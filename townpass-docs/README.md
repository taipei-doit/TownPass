## 使用說明

- 每頁保留來源網址、原始路徑與擷取日期作為 YAML front matter。
- 文件內指向本文件集其他頁面的連結已改為本地相對連結；同站圖片已下載到 `assets/`。
- 文件只反映擷取當天網站公開的繁體中文 `/docs/` 內容；需確認現況時請回看各頁的官方來源網址。
- 程式範例與表格由網站渲染後的 HTML 轉成 Markdown；互動式呈現可能無法在離線文字中完全重現。
- 對無法取得正文或目前呈現空白的頁面，對應檔案會保留狀態說明，避免漏掉文件清單中的項目。
