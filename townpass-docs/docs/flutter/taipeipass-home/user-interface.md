# 介面

## 介面介紹

首頁主要呈現市府及在地地區相關活動資訊，讓使用者可以快速了解所有最新活動，並為每個活動項目設定連結，點擊後可以查看更多有關該活動的詳細內容。 另外也提供快捷市府服務專線按鈕，讓使用者可以一鍵撥號，快速聯絡。
