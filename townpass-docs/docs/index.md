# 關於城市通

城市通是臺北市政府打造的一款開源專案。隨著智慧城市的發展，城市管理和市民服務的數位化需求日益增長。一個全新數位時代的來臨，我們目標是讓市民共同參與，結合第三方的智慧與創新，使臺北市數位生活更加便利。

城市通不僅僅是一個應用程式，更是一個開放的社群項目。通過開源，每一位市民都能參與到應用程式發想、開發和優化。不僅能提升市民的參與感和滿意度，還能充分利用集體智慧，使應用程式不斷完善，真正服務於民。此外，我們還期望各縣市能夠廣泛應用城市通的開源架構，整合現有市政服務系統，讓各縣市可以快速擁有專屬應用，提升數位治理水平。

開源是推動技術進步和社會發展的重要力量，通過開源，城市通將成為一個不斷進化的平臺，吸引多方開發者共同參與。歡迎各方高手提交程式、反饋問題、提供建議，甚至開發新的功能與創意，共同完善城市通，邁向智慧城市。
