# 票券列表(搜尋)

## /coupon/list

### 列表

票券列表會顯示所有入場券、優惠券。

使用者透過主頁的更多按鈕或是主頁入場券的人氣特展皆可進入列表。

![入場券列表](../../../assets/0c33bb0033c88397b591.png)

![優惠券列表](../../../assets/ac0e95e257c7da61aa8b.png)

列表顯示的資料都與主頁的熱門相同，皆來自 [ticket_list](main-page.md#入場券-ticket-list) 與 [coupon_list](main-page.md#優惠券-coupon-list) 的定義。

### 搜尋

列表頁面同時含有搜尋功能，可以針對票券的名稱做模糊搜尋。

使用者可以透過主頁點擊搜尋 input 直接進入搜尋環節，或是直接在列表頁面做搜尋。

![票券搜尋](../../../assets/dba2208f2580cf9a70ae.png)

![票券搜尋-無結果](../../../assets/d341e4f3a71e30c66c91.png)
