# 優惠券簡介

## 關於優惠券

優惠券是城市通的一項重要功能，使用者可以透過此功能查詢場館入場券與搜尋各類別優惠券。 使用者不必再到各場館官網或是店家搜尋相關票券，只要使用此功能就能取得所有相關票券資訊。

ℹ️ 資訊

優惠券是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

讓開發者發揮創意，將你們覺得適合放在城市通的票券，透過 JSON 設計，為城市通添加各式各樣的入場券與優惠券。

讓城市通的內容更加多采多姿、引人入勝，打造出屬於城市通優惠券從介紹到詳細資訊的一條龍客製化服務。
