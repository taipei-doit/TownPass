# Q & A • 常見問題簡介

## 關於常見問題

Q & A 功能旨在提供使用者便捷的解答搜尋服務，讓使用者能輕鬆找到所需答案並獲取相關資訊。

ℹ️ 資訊

Q & A 功能是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

設計此功能的目的在於：

1. 讓充滿創意的開發者，透過簡單的 JSON 設計，顯示不同問題的類別與解答，為 Q & A 加入您覺得適合的服務以及相關資訊。
2. 透過統整資訊設計出易用的問題解答功能，使常見問題呈現更加直觀、便捷，提升使用者體驗。

## 主要功能

Q & A 功能主要展示在頁面上，可以自行新增需要顯示的問題，並且可根據需求自定義問題顯示的狀態等訊息。這讓使用者能夠更方便地找到所需答案並獲取相關資訊。
