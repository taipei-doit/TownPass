# 市政訊息訂閱簡介

## 關於市政訊息訂閱

市政訊息訂閱功能旨在提供即時資訊，讓使用者能夠訂閱與市政相關的各項便民服務，包括交通動態、圖書到期通知、旅遊資訊等服務，方便市民掌握最新的市政動態與生活便利資訊。

ℹ️ 資訊

市政訊息訂閱是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

提供清晰易讀的介面，讓使用者可以快速選擇並管理其訂閱的服務項目，提升生活便利性，減少因資訊不全或延誤造成的困擾。

## 主要功能

市政訊息訂閱功能主要展示在頁面上，使用者可以根據需求選擇並訂閱感興趣的市政服務，例如交通動態、圖書到期提醒、旅遊資訊等。並可根據訂閱的內容調整其生活安排。
