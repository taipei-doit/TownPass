# 臨櫃叫號簡介

## 關於臨櫃叫號

臨櫃叫號功能旨在提供即時資訊，讓使用者能方便查詢各個機關的服務櫃檯狀況，包括目前的叫號情況與等待人數，幫助使用者更好地規劃到訪時間。

ℹ️ 資訊

臨櫃叫號功能是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

設計此功能的目的是：

1. 讓使用者能夠即時掌握各個機關服務地點的櫃檯狀況，提供目前叫號號碼、等待人數及櫃檯位置等詳細資訊。
2. 提供清晰易讀的列表和資訊，讓使用者快速瀏覽所有櫃檯的即時動態，有效減少等待時間，提升使用者的服務體驗。

## 主要功能

臨櫃叫號功能主要展示在頁面上，使用者可以查詢各個機關的服務櫃檯情況，並根據需求查看不同櫃檯的叫號進度。該功能可設計成即時更新，確保使用者隨時掌握最新的等待情況，並可根據動態調整前往櫃檯的時間安排。
