# 申辦服務簡介

## 關於申辦服務

申辦服務是城市通的一項重要功能，使用者可以透過此功能申請各政府機關提供的申請項目。 申辦服務將各種申請項目集大成，使用者可以一目了然找到他想申請的服務，並同時提供該服務所需提交之表單與進度查詢。

ℹ️ 資訊

申辦服務是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

讓充滿創意的眾家好手，透過簡單的 JSON 設計，為申辦服務加入你們覺得適合的服務以及它對應的表單格式。

亦同時開源程式碼，讓對前端開發有興趣的開發者，透過巧思設計出不一樣的服務元素與表單元件。

最終使申辦服務的服務內容更加豐富、多元與便利。
