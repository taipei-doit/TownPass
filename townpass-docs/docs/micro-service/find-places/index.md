# 找地點簡介

## 關於找地點

找地點功能旨在提供使用者便捷的地點搜尋服務，讓使用者能輕鬆找到所需位置並獲取相關資訊。

ℹ️ 資訊

找地點是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

設計此功能的目的在於：

1. 讓充滿創意的開發者，透過簡單的 JSON 設計顯示地點資訊，為找地點加入您覺得適合的服務以及相關資訊。
2. 透過統整資訊設計出易用的地點搜尋功能，使地點資訊呈現更加直觀、便捷，提升使用者體驗。

最終目的是使找地點的內容更加豐富、多元、便捷，並提供更便民的服務。

## 主要功能

找地點功能主要展示在地圖上，可以自行新增需要顯示的地點，並且可根據需求自定義地點顯示的狀態等訊息。這讓使用者能夠更方便地找到所需位置並獲取相關資訊。
