# 有話要說簡介

## 關於有話要說

有話要說功能旨在提供各種類型通報表單以及 1999 服務專線撥打，讓市民可以第一時間，通報各種事件，尋求最快速且正確的協助。

ℹ️ 資訊

有話要說是城市通的微服務功能，屬於網頁開發範疇，城市通透過 webview 的方式將此功能嵌入 app 中，開發此功能請 fork [下載與設定專案](../introductions/project-setup.md) 提到的城市通微服務專案。

## 設計目的

讓開發者透過簡單的 JSON 資料定義，新增、刪除市民可通報的事件類型，並同時提供進度查詢，查詢通報的事件處理進度，打造出市民方便使用的多元通報介面。
